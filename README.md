# Mentora Consciente · Campus online

Campus full-stack para cursos, membresías y administración.

- Registro e inicio de sesión de alumnos
- Membresías y compra individual de cursos
- Campus privado con permisos por alumno
- PDFs protegidos y control de descargas
- Panel de administración para cursos, alumnos y ventas
- Integración PayPal preparada mediante variables de entorno
- Vista previa del campus según tipo de membresía

## Seguridad

Las credenciales reales, la base de datos y los archivos privados no se guardan en GitHub. Se configuran mediante variables de entorno en el servidor/hosting.

Ver `.env.example` y la documentación del proyecto antes de publicar en producción.
